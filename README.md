# Insel

Die Dynamic Island für die MacBook-Notch, mit Agenten, Ablage, Musik, Timern und Terminen. Ab macOS 14.

Dieses Repo enthält nur die fertigen App-Versionen, keinen Quellcode.

## Installieren

1. **[Insel.dmg herunterladen](https://github.com/M1cksa/insel-releases/releases/latest/download/Insel.dmg)** (immer die neueste Version)
2. Öffnen und **Insel auf den Ordner „Applications“ rechts ziehen**
3. Insel aus „Programme“ starten. macOS blockiert den ersten Start, weil Insel nicht über den App Store kommt: **Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“**. Das ist nur einmal nötig.

Updates kommen danach von selbst: Insel sucht einmal am Tag und fragt, bevor es installiert.

---

**English:** [Download Insel.dmg](https://github.com/M1cksa/insel-releases/releases/latest/download/Insel.dmg), open it and drag Insel onto the Applications folder. On first launch macOS blocks it: go to System Settings → Privacy & Security → "Open Anyway" (once). Updates install from within the app afterwards.

**Español:** [Descarga Insel.dmg](https://github.com/M1cksa/insel-releases/releases/latest/download/Insel.dmg), ábrelo y arrastra Insel a la carpeta Aplicaciones. En el primer inicio macOS lo bloquea: Ajustes del Sistema → Privacidad y seguridad → «Abrir igualmente» (una sola vez). Después, las actualizaciones llegan desde la propia app.
